PrimeSecure PC Setup - three-device pilot

Extract the complete ZIP, then double-click PrimeSecure Setup.exe on a 64-bit Windows 10/11 PC. No terminal, Android Studio, SDK installation or Windows administrator permission is needed. The .NET Framework supplied with Windows is used.

On the unlocked Primebook, enable Developer options and Wireless debugging. Keep it on the same Wi-Fi as the PC. In Pair using pairing code, enter the pairing address and six-digit code in the PC window and click Pair. The pairing window must stay open. If discovery does not find the connection, use the separate connection address from Wireless debugging's main screen and click Connect. Some school networks isolate clients; use a trusted technician hotspot if needed. USB is also available when the Primebook exposes an authorized debugging connection; a charging-only USB-C port cannot provide this route.

Select the correct connected device, enter its dashboard enrollment key and click Prepare Primebook. The app checks the device, installs the bundled verified release, assigns Device Owner through Android's authorized debugging channel, requests media access and opens enrollment automatically. The progress bar tracks actual setup stages, not a guessed transfer percentage. First apps, wallpaper and notes continue on the Primebook's existing preparation screen. Check that the expected student appears online in the dashboard before handing it out.

Use Next device to clear the previous connection/key. Each student needs their own enrollment key. Existing enrollments are kept; this tool does not silently reassign a student. Already connected devices may still appear in the list, so select the intended hardware explicitly. Save log exports setup events without the enrollment/pairing codes. Codes are not saved with the kit.

The tool uses a separate local connection-server port (5047), stores its operator pairing key under the current Windows user's LocalAppData, and never exposes an unauthenticated debugging listener to the network. Pairing trust remains until revoked on the Primebook. After provisioning/testing, turn Wireless debugging off and forget the operator PC when access is no longer needed. Do not distribute the operator PC's pairing-key folder to students.

There is no automatic wipe, account removal, administrator removal, setup-completed flag change, forced downgrade or test-only installation. Android may refuse Device Owner if accounts or another owner are present. The window reports that refusal; resolve it through supported settings or manufacturer provisioning. Stop waiting cancels the PC's wait, but Android may finish an operation already accepted. Check its state before retrying.

The Windows executable is locally built and not Authenticode signed. This kit includes PrimeSecure 0.8.5 (22), signed by the existing fleet APK key and not test-only. Android platform-tools and their NOTICE are included in tools/. Source and build/tests: tools/pc-setup in the PrimeSecure repository. Windows/process tests do not prove PrimeOS pairing/provisioning; pilot this kit on one device before using it on all three, and test those three before 300.
