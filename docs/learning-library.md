# School learning library

Prepared and imported on 15 October 2026 for the shared RoboKorda library, with access enabled only for Rusununguko ZIMFEP High School (`14eea188-73b1-40bc-8f8d-15afbea27ffa`). Other schools can opt in later. The live import verified every uploaded file by downloading it from private storage and checking its size and SHA-256 before publishing the catalog batch.

The collection contains **41 files, 166,214,841 bytes** (158.5 MiB): 11 full publisher textbooks, 19 original short revision/practice notes, five original practice papers with answer or marking guidance, and six original study diagrams. There are **no videos**. Every catalog row includes its form, subject, category, attribution, licence, origin and review limits. Files and the complete manifest are staged under `artifacts/learning-library/` (ignored build artifacts).

These are secondary-school **topic supplements**, not an official or fully mapped ZIMSEC course. South African CAPS grades are retained in textbook titles; the Zimbabwe form folder is a suggested study grouping, not grade equivalence. A teacher must check the current ZIMSEC syllabus and the learner's level before assigning a chapter. The advanced resources are selected topic practice rather than complete A-level courses. The Shona sheets have English instructions and Shona response tasks; native-language teacher review and current prescribed-text selection are still needed.

## Import and verification

The small transfer archive contains the manifest, helpers and the 30 original files; the 11 large textbooks are downloaded directly on the server from the official publisher, with their already-verified size and SHA-256 pinned in the manifest. Neither downloader nor importer disables TLS verification. Publisher changes fail the checksum check and require a fresh rights/content review.

```powershell
python artifacts/learning-library/import-learning-library.py --bundle-dir artifacts/learning-library
node artifacts/learning-library/test-import.cjs
```

On the self-hosted server, after transferring/extracting the small bundle:

```sh
python3 download-learning-library-server.py --bundle-dir /root/primesecure-learning-library
python3 import-learning-library.py --bundle-dir /root/primesecure-learning-library --apply --report-file /root/primesecure-learning-library/import-report.json
```

The importer validates all 41 local files, checks existing bucket MIME/file-size limits, the storage service's global limit and actual host free space, and records current storage metadata usage. The largest selected PDF is 27,695,638 bytes. It does not raise limits, split ND books or change bucket access. Credentials are read from `supabase-kong` into process memory; they are not logged or saved.

Each file uploads to an immutable `shared/learning/<checksum-prefix>/<filename>` object in the **private** `primesecure-hub` bucket and is downloaded back to verify its size and hash. Only after every object verifies does one SQL transaction publish the complete metadata batch and selected school's access. Deterministic identities and content checks make identical reruns idempotent; changed/withdrawn existing resources cause a conflict rather than silently restoring or overwriting them. A metadata/access backup is saved under `/root/primesecure-backups/` before mutation. Existing apps, policies, settings, teacher resources and other schools' access are preserved. The helper does not install apps or create videos.

Local verification covers PDF parsing/page counts, PNG signatures/dimensions, every file hash/size, form/subject/category coverage, attribution fields, and isolated PostgreSQL tests for imports, reruns, preserved existing records and conflict rollback. It does not prove physical Primebook viewing, background-download behaviour or teacher acceptance; those require a device/classroom pilot.

The completed live import report is saved at `/root/primesecure-learning-library/import-report.json`, with a local copy at `artifacts/learning-library/live-import-report.json`. It records 41 published resources and 166,214,841 verified bytes. The pre-import metadata/access backup is `/root/primesecure-backups/learning-import-20261015T215804283694Z.json`. Existing policies, settings and app installations were not changed by this import.

An isolated enrolled-device account also downloaded an original PDF and PNG through authenticated private storage with exact size/hash matches. Unauthenticated, anonymous, public-path and revoked-access downloads were denied. Both temporary QA access grants were removed, restoring access to the selected school only. Evidence: `artifacts/learning-library/live-device-flow-verification.json`. This verifies the live catalog/storage flow, not physical-device rendering.
